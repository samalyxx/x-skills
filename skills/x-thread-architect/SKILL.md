# Thread Architect

Create a reviewable X deliverable from supplied material. This bundle does not claim live platform access, scrape accounts, or publish by default.

## Intake

- identify the account owner, target audience, objective, and desired response;
- collect source facts, examples, approved language, required disclosures, and relevant assets;
- identify links, mentions, timing, format, or accessibility requirements;
- name any claim, account action, or policy question requiring human review.

## Workflow

1. State a one-sentence brief: audience, problem or interest, core point, evidence, and objective.
2. Choose a platform-native structure that serves the source rather than a generic engagement template.
3. Draft only from supplied facts. Preserve attribution, qualifications, and ownership boundaries.
4. Check that the opening, body, and call to action make the same promise.
5. Run the quality gate in `references/x-writing.md` and route risky or uncertain material for review.

## Output

Return `Brief`, `Draft or action queue`, `Editorial notes`, `Facts to verify`, and `Assumptions`. For an explicitly requested schedule or publish action, read `references/socialbu-publishing.md`: show the exact unchanged preview, account, action, and time, then require fresh confirmation.
